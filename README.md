# 🧪 AI 测试助手（方案B · 求职实战项目）

> 一个把"软件测试工作 AI 化"的完整工具：输入需求文档 → 自动生成测试用例 → 自动生成 pytest 自动化脚本 → 自动执行并智能分析报告。
> 全程本地运行（Ollama + llama3.1:8b），**零 API 成本**，和方案A同技术栈。

---

## 🎯 项目背景与解决痛点

测试人员日常要写大量测试用例、写回归脚本、分析测试报告，重复性高、耗时多。
本工具用大模型把这些重复劳动自动化：**输入需求 → 批量产出用例和脚本 → 自动跑 → 智能分析**，测试同事直接拿走 Excel 用，回归脚本一键生成。

---

## 📁 项目结构

```
ai-test-assistant/
├── config.py          # 统一配置（模型、输出目录、接口配置、对抗用例）
├── prompts.py         # 提示词模板（用例/脚本/报告/接口用例）
├── llm_client.py      # 大模型调用封装（本地Ollama）
├── testcase_gen.py    # 生成结构化测试用例 + 导出Excel
├── script_gen.py      # 把用例转成pytest脚本
├── runner.py          # 执行pytest + 智能分析报告
├── api_test.py        # 接口测试（真实系统）：生成接口用例+真实请求脚本+执行+分析
├── llm_eval.py        # 大模型安全评测（对抗Prompt测试）
├── app.py             # Streamlit网页主界面（5个功能页）
├── requirements.txt   # 依赖清单
└── docs/              # 示例需求文档
```

## 🚀 快速开始（4步）

### 第0步：确认Ollama与模型（方案A已装则跳过）
```bash
ollama pull llama3.1:8b
ollama list   # 确认能列出模型
```

### 第1步：安装依赖
```bash
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 第2步：启动网页
```bash
python -m streamlit run app.py
```
浏览器打开 http://localhost:8501，有5个功能页。

### 第3步：使用流程（按顺序）
1. 【生成测试用例】页：粘贴需求 → 点生成 → 得到Excel + 用例预览
2. 【生成pytest脚本】页：点生成 → 得到可运行脚本
3. 【执行测试&分析】页：点执行 → 看到pytest输出 + 大模型智能分析
4. 【接口测试】页（**真实系统测试**）：填真实接口地址 → 点生成 → AI 生成接口用例 + 真正调用该接口的脚本 → 执行 → 智能分析
5. 【大模型安全评测】页：点开始 → 看模型能否拦截对抗Prompt

## ✨ 难点与优化（README必写，面试就讲这些）

1. **结构化输出控制**
   - 提示词强制 JSON 输出 + 用代码剥壳（去```、去解释文字），保证程序能稳定解析
   - 面试点：大模型输出不稳定，我用"格式约束 + 后处理清洗"双保险
2. **用例覆盖维度设计**
   - 强制覆盖"正常/边界/异常/兼容"四类场景，符合测试方法论
3. **报告智能分析**
   - 把 pytest 原始输出交给大模型，自动归类失败原因、给修复建议，替代人工读日志
4. **接口测试（真实系统，进阶亮点）**
   - 输入真实接口地址 → AI 生成接口用例 → 生成**真正用 requests 请求该接口**的 pytest 脚本 → 执行 → 智能分析
   - 面试点：不是测假函数，而是能接真实系统，这是测试岗位最对口的能力
5. **安全评测（结合测试背景加分）**
   - 构造越狱/注入/诱导对抗 Prompt，验证大模型边界，输出评测结论

## 📝 命令行使用（不启动网页也能用）

```bash
# 1. 生成测试用例并导出Excel
python testcase_gen.py "登录功能：用户输入正确的用户名密码可登录"

# 2. 生成pytest脚本（需要先把用例存成JSON）
python script_gen.py output/cases.json

# 3. 执行测试并智能分析
python runner.py

# 4. 接口测试（真实系统，需要联网访问被测接口）
python api_test.py "登录接口：POST https://httpbin.org/post，传用户名和密码，成功返回200"

# 5. 大模型安全评测
python llm_eval.py
```

## ⚠️ 常见问题

| 问题 | 解决 |
|---|---|
| 提示连接Ollama失败 | 确认 ollama serve 已启动（或右下角小羊图标在） |
| 生成用例报"未返回有效JSON" | 多为网络/模型卡顿，重试；或换更稳的模型 |
| pytest不识别脚本 | 确认脚本在 scripts 目录、函数以 test_ 开头 |
| 中文字符乱码 | 确认txt/需求为UTF-8，Windows cmd可加 `chcp 65001` |
